# Dev Kit

A loaded kit to do pretty much anything you want in the Beta worlds. Please use it responsibly.

## Install

1. Download this repo (Code > Download ZIP) and unzip it.
2. Copy the `dev-kit` folder into `C:\ProgramData\Jagex\RuneScape-BETA\dev_plugins\`
3. In game, open the console with Alt + `` ` ``, type `prf`, then `pon dev-kit`
